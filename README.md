# Thanh Nguy — Developer Portfolio

Production-grade developer portfolio for **Nguy Van Thanh (Thanh Nguy)**, Middle Full-stack Developer (Frontend Major).

## Tech Stack
- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```

## One-Click Deploy to Vercel
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "feat: initial portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/thanh-nguy-portfolio.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) -> **Add New Project** -> Import this GitHub repo.
3. Framework Preset: **Vite** (Vercel will auto-detect).
4. Click **Deploy**!
